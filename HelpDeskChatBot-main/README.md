# HelpDeskChatBot

Учебный проект по разработке интеллектуального Telegram-бота для поиска контактной информации сотрудников университета на основе текстовых запросов пользователей.

Проект разработан в рамках дисциплины **«Современные интеллектуальные сетевые сервисы»**.

Основная задача - реализовать сервис, который получает вопрос пользователя на естественном языке, анализирует его и подбирает сотрудников, чьи должности наиболее близки к тематике запроса.

В проекте используются методы обработки естественного языка (NLP), TF-IDF-векторизация, математические метрики сходства, асинхронный парсинг и многопоточность.

Основной pipeline:

1. Парсер получает информацию о сотрудниках с сайта университета.
2. Собранные данные сохраняются в `data.json`.
3. Пользователь отправляет текстовый запрос Telegram-боту.
4. Запрос и должности сотрудников проходят предварительную обработку.
5. Тексты преобразуются в TF-IDF-векторы.
6. Вычисляются коэффициенты сходства.
7. Бот возвращает контактную информацию подходящих сотрудников.

## Реализация

### Асинхронный парсинг

Для сбора информации используются `aiohttp`, `asyncio` и `BeautifulSoup`.

Парсер получает данные с трёх страниц сайта университета и извлекает:

- ФИО сотрудника;
- должность;
- контактный телефон.

Загрузка страниц организована конкурентно с помощью `asyncio.gather()`.

Пока одна "корутина" ожидает сетевой ответ, цикл событий может выполнять другие задачи. После завершения загрузки результаты объединяются и сохраняются в JSON-файл.

### Обработка естественного языка

Для предварительной обработки текстов используется библиотека `NLTK`.

Функция `preprocess()` выполняет:

1. Приведение текста к нижнему регистру.
2. Удаление пунктуации.
3. Токенизацию.
4. Удаление русских стоп-слов.
5. Стемминг с использованием `RussianStemmer`.

Одинаковая предварительная обработка применяется к запросу пользователя и должностям сотрудников.

### TF-IDF

Для преобразования текстов в числовые векторы используется `TfidfVectorizer` из библиотеки `scikit-learn`.

TF-IDF учитывает частоту появления слов в документе и их информативность относительно остальных документов.

Общая формула TF-IDF:

$$
w_{x,y}=tf_{x,y}\log\left(\frac{N}{df_x}\right)
$$

где:

- $w_{x,y}$ - TF-IDF-вес слова $x$ в документе $y$;
- $tf_{x,y}$ - частота слова $x$ в документе $y$;
- $df_x$ - количество документов, содержащих слово $x$;
- $N$ - общее количество документов.

Запрос пользователя располагается в нулевой строке TF-IDF-матрицы, а остальные строки соответствуют должностям сотрудников.

## Метрики сходства

Для сравнения полученных векторов реализованы три метрики.

### 1. Cosine similarity

Косинусное сходство измеряет близость направлений двух векторов.

$$
\cos(\theta)=\frac{A\cdot B}{\|A\|\|B\|}
$$

где:

- $A$ и $B$ - сравниваемые векторы;
- $A\cdot B$ - скалярное произведение;
- $\|A\|$ и $\|B\|$ - длины векторов.

Чем ближе значение к `1`, тем выше сходство.

Косинусное сходство является основной метрикой отбора сотрудников. Для отображения результатов используется порог `0.20`.

### 2. Weighted Jaccard similarity

В проекте реализован взвешенный коэффициент Жаккара, который рассчитывается на основе TF-IDF-весов.

$$
J(A,B)=
\frac{\sum_i\min(A_i,B_i)}
{\sum_i\max(A_i,B_i)}
$$

где $A_i$ и $B_i$ - соответствующие веса признаков сравниваемых векторов.

Числитель представляет сумму минимальных весов, а знаменатель - сумму максимальных.

### 3. Euclidean distance

Евклидово расстояние измеряет расстояние между двумя нормализованными TF-IDF-векторами.

$$
d(A,B)=\sqrt{\sum_i(A_i-B_i)^2}
$$

Чем меньше расстояние, тем ближе векторы.

Для преобразования расстояния в показатель сходства используется формула:

$$
S=\frac{1}{1+d(A,B)}
$$

Таким образом, более близкие векторы получают больший показатель сходства.

Все три рассчитанные метрики включаются в результат, отправляемый пользователю. Отбор сотрудников выполняется на основе косинусного сходства.

## Пример работы

Рассмотрим условный пример поиска сотрудника, ответственного за общежитие. Данные сотрудника и числовые значения метрик приведены для демонстрации принципа работы алгоритма.

### 1. Запрос пользователя

Пользователь отправляет Telegram-боту сообщение:

```text
Как мне попасть в общежитие Горняк?
```

Бот получает текст сообщения и передаёт его функции `get_answer()`.

### 2. Предварительная обработка текста

Функция `preprocess()` выполняет следующие операции:

- Приведение текста к нижнему регистру.
- Удаление пунктуации.
- Токенизацию - разделение текста на отдельные слова.
- Удаление русских стоп-слов.
- Стемминг - приведение слов к их основам.

Например, стемминг позволяет уменьшить различия между грамматическими формами одного слова:

```text
общежитие  - общежит
общежития  - общежит
общежитием - общежит
```

В результате предварительной обработки запрос преобразуется примерно к следующему виду:

```text
попаст общежит горняк
```

Аналогичную обработку проходят должности сотрудников.

Предположим, в `data.json` содержится следующая запись:

```json
{
  "ФИО": "Иванов И. И.",
  "Должность": "Заведующий общежитием Горняк",
  "Телефон": "+7XXXXXXXXXX"
}
```

После предварительной обработки должности получаем примерно:

```text
заведующ общежит горняк
```

Таким образом, в запросе и должности присутствуют общие основы слов: `общежит` и `горняк`.

### 3. TF-IDF-векторизация

Предварительно обработанный запрос и должности сотрудников объединяются в общий корпус документов.

`TfidfVectorizer` преобразует их в числовые векторы, используя общий словарь признаков.

Упрощённый пример:

```text
                       попаст  общежит  горняк  заведующ

Запрос пользователя      0.5     0.6     0.6      0.0

Должность сотрудника     0.0     0.6     0.6      0.5
```

Значения приведены исключительно для иллюстрации. Фактические TF-IDF-веса зависят от всего корпуса документов.

### 4. Вычисление сходства

После построения TF-IDF-матрицы алгоритм вычисляет три метрики:

- Косинусное сходство.
- Взвешенное сходство Жаккара.
- Евклидово расстояние.

Для демонстрации предположим, что были получены следующие результаты:

```text
Косинусное сходство:                  0.68

Взвешенное сходство Жаккара:          0.47

Евклидово расстояние:                 0.80
Преобразованное евклидово сходство:   0.56
```

Основным критерием отбора сотрудников является косинусное сходство.

Поскольку в данном примере значение `0.68` превышает установленный порог `0.20`, сотрудник проходит отбор.

### 5. Формирование ответа

Алгоритм сопоставляет результаты вычислений с исходной записью сотрудника из `data.json` и формирует текстовое сообщение.

Telegram-бот отправляет пользователю ответ примерно следующего вида:

```text
Возможно вам помогут:

👤 Иванов И. И.
💼 Заведующий общежитием Горняк
📞 +7XXXXXXXXXX

Коэффициенты сходства:
- косинусное сходство: 0.68
- коэффициент сходства Жаккара: 0.47
- балл подобия по Евклидову расстоянию: 0.56
```

Таким образом, бот преобразует текстовый запрос пользователя в числовое представление, сравнивает его с должностями сотрудников и возвращает контактную информацию тех сотрудников, которые удовлетворяют установленному критерию сходства.

## Многопоточность

Для независимой работы Telegram-бота и планировщика обновления данных используется модуль `threading`.

Планировщик работает в отдельном фоновом потоке, созданном с параметром `daemon=True`.

Библиотека `schedule` обеспечивает периодический запуск парсера с интервалом 10 минут.

Благодаря разделению потоков бот может продолжать получать и обрабатывать сообщения во время выполнения планировщика.

## Установка и запуск

Установка основных зависимостей:

```bash
pip install pyTelegramBotAPI aiohttp beautifulsoup4 nltk scikit-learn numpy scipy schedule
```

Загрузка ресурсов NLTK:

```python
import nltk

nltk.download("stopwords")
nltk.download("punkt")
nltk.download("punkt_tab")
```

Для запуска необходимо получить токен Telegram-бота через BotFather и настроить его в `bot.py`.

Перед первым запуском бота необходимо сформировать `data.json`:

```bash
python -c "from parsing import parse; parse()"
```

Запуск:

```bash
python bot.py
```
