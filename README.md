# Educational Projects

Сборник учебных проектов на Python, посвящённых backend-разработке, машинному обучению (ML), обработке естественного языка (NLP) и рекомендательным системам.

Проекты разработаны в рамках университетских дисциплин и самостоятельной практики. Они демонстрируют применение алгоритмов, методов обработки данных, сетевых технологий и интеграции ML-моделей в программные приложения.

## Проекты

### 1. [HelpDeskChatBot](HelpDeskChatBot-main/)

Интеллектуальный Telegram-бот для поиска контактной информации сотрудников университета на основе текстовых запросов.

**Реализовано:**
- Асинхронный парсинг веб-страниц с использованием `aiohttp` и `asyncio`.
- Предварительная обработка русского текста средствами `NLTK`.
- TF-IDF-векторизация и сравнение текстов с помощью косинусного сходства, взвешенного коэффициента Жаккара и евклидова расстояния.
- Фоновое обновление данных с использованием многопоточности.

**Технологии:** Python, pyTelegramBotAPI, aiohttp, BeautifulSoup, NLTK, scikit-learn, NumPy, SciPy.

[Подробное описание проекта](HelpDeskChatBot-main/README.md)

### 2. [ML-service](ML-service-main/ML-service-main/)

Учебный веб-сервис для классификации текстовых сообщений на основе предобученной модели машинного обучения.

**Реализовано:**
- REST API с использованием `FastAPI`.
- Интеграция предобученной модели `skandavivek2/spam-classifier` из Hugging Face.
- Классификация сообщений на категории `SPAM` и `HAM`.
- Возврат результатов классификации и показателя уверенности модели.
- Тестирование ML-компонента и API.

**Технологии:** Python, FastAPI, Hugging Face Transformers, PyTorch, Pydantic, Pytest.

[Подробное описание проекта](ML-service-main/ML-service-main/README.md)

### 3. [Recommender System for Sports Store](recommender-system-sports-store/)

Учебная рекомендательная система спортивного магазина, использующая пользовательские предпочтения и текстовые характеристики товаров для формирования рекомендаций.

**Реализовано два подхода:**
- **Item-based collaborative filtering** - поиск похожих товаров на основе пользовательских оценок.
- **Content-based filtering** - рекомендации на основе TF-IDF-векторизации текстовых описаний товаров и косинусного сходства.

Проект демонстрирует работу рекомендательных алгоритмов и применение различных способов представления данных.

**Технологии:** Python, scikit-learn, TF-IDF, разреженные матрицы CSR.

[Подробное описание проекта](recommender-system-sports-store/README.md)
